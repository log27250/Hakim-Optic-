# نظام الحكيم لإدارة مراكز البصريات — v174

حزمة الإصدار المصححة تحتوي ملفات التطبيق اللازمة للنشر على GitHub Pages وتشغيل نسخة PWA.

## الملفات
- `index.html` — واجهة النظام ومنطق التشغيل والحفظ.
- `sw.js` — Service Worker مع مفتاح cache جديد لإجبار الأجهزة على تحميل النسخة المصححة.
- `manifest.webmanifest` و`offline.html` والأيقونات.

## النشر الآمن
1. احتفظ بنسخة من ملفات الموقع الحالية.
2. خذ نسخة احتياطية من بيانات المركز من داخل النظام قبل النشر.
3. فك الضغط وارفع **محتويات المجلد مباشرة** إلى جذر مستودع GitHub Pages مع استبدال الملفات.
4. بعد اكتمال النشر، أغلق التطبيق والمتصفح وافتح الموقع مجدداً. لا تمسح بيانات الموقع المحلية إذا لم تكن لديك نسخة احتياطية مؤكدة.

## الحفاظ على إصلاح الحفظ في v170
- إزالة اعتماد طبقة المعاملة على مقارنة نصوص `localStorage` حرفياً لتقرير نجاح الحفظ.
- الاعتماد على تحقق دالة الحفظ الأساسية من قراءة الفاتورة المحفوظة مرة أخرى باستخدام معرّفها.
- الإبقاء على استرجاع مخزون العملية عند فشل الحفظ قبل كتابة سجل الفاتورة.
- تمرير نتيجة الحفظ الفعلية من `saveInvoice` إلى `saveCombinedInvoiceInternal` بدلاً من إسقاطها.
- تحديث مفتاح Service Worker إلى `hakim-optics-offline-v170-save-path-fix` لتجنب تقديم ملفات التطبيق القديمة من cache.

## حدود الاختبار
تم فحص تركيب JavaScript ومقاطع الحفظ ومقارنة مسار v148 مع v169، ولم يتم تنفيذ بيع حقيقي على جهاز المركز أو اختبار حساب Supabase الحي من هذه البيئة. لم يتم تعديل قاعدة البيانات أو سياسات RLS أو أي بيانات مرضى/مبيعات حية.
