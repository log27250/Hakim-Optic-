Hakim Optic - نسخة تطبيق قابلة للتثبيت

هذه النسخة لا تغيّر منطق النظام الداخلي. تمت إضافة طبقة PWA فقط:
- manifest.json
- Service Worker
- أيقونات التطبيق
- تسجيل Service Worker داخل index.html

على Windows:
1) ارفع الملفات إلى GitHub Pages أو استضفها عبر HTTPS.
2) افتح الموقع في Chrome أو Edge.
3) اختر Install Hakim Optic / تثبيت التطبيق.
4) سيظهر كبرنامج مستقل في Start Menu/سطح المكتب.

على Android:
1) افتح الرابط في Chrome.
2) اختر Install app / تثبيت التطبيق.
3) سيظهر Hakim Optic كتطبيق مستقل.

ملاحظة APK:
هذه ملفات PWA وليست APK جاهزاً. يمكن تغليف نفس الواجهة لاحقاً باستخدام Capacitor لإخراج APK/AAB بدون إعادة كتابة النظام.
